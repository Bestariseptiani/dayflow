Kebijakan Privasi Dayflow

Terakhir diperbarui: 18 November 2026. Dayflow adalah aplikasi pengatur tugas dan pengingat yang dibuat sebagai proyek kelompok kuliah (MK Literasi AI dan Inovasi, PJJ Komunikasi, UNSIA). / Dayflow is a task and reminder app built as a university group project.

Data yang digunakan

  • Akun Google (opsional). Jika kamu memilih "Masuk dengan Google", Dayflow meminta izin untuk membuat event di Google Calendar-mu (calendar.events) dan membaca alamat emailmu (userinfo.email) untuk ditampilkan di layar. Event hanya dibuat saat kamu menekan tombol simpan atau mengatur tugas.
  • Token akses Google hanya disimpan sementara di memori browsermu dan tidak dikirim atau disimpan di server Dayflow.
  • Tugas dan riwayat (judul, tanggal, jam, lokasi) disimpan di penyimpanan lokal browsermu (localStorage) dan tidak dikirim ke server, kecuali untuk fitur notifikasi di bawah.
  • Notifikasi pengingat (opsional). Jika kamu mengaktifkan notifikasi, server menyimpan alamat langganan notifikasi perangkatmu serta judul, lokasi, dan waktu tugas yang kamu jadwalkan. Data ini dihapus otomatis setelah notifikasi terkirim atau saat tugas dibatalkan.
  • Cuaca. Lokasi perkiraanmu (dari izin lokasi browser atau alamat IP) dipakai untuk menampilkan cuaca melalui layanan pihak ketiga (Open-Meteo, BigDataCloud, ipapi.co). Dayflow tidak menyimpannya.

Penggunaan dan pembagian

Data hanya dipakai untuk menjalankan fitur di atas. Dayflow tidak menjual data dan tidak membagikannya ke pihak lain untuk iklan. Penggunaan data dari Google API mengikuti Kebijakan Data Pengguna Layanan Google API, termasuk persyaratan Penggunaan Terbatas.

Mencabut akses dan menghapus data

  • Cabut izin Google kapan saja di myaccount.google.com/permissions.
  • Matikan notifikasi lewat tombol "Matikan" di Dayflow atau pengaturan situs di browser.
  • Hapus data lokal dengan menghapus data situs di browser.
