🔗 Hubungkan Google Calendar

Belum terhubung. Tugas disimpan sebagai file .ics.

Cara dapat Client ID:

  1. Buka console.cloud.google.com, buat project, lalu aktifkan Google Calendar API.
  2. Di OAuth consent screen pilih External, lalu tambahkan emailmu di Test users.
  3. Credentials → Create → OAuth client ID → Web application.
  4. Di Authorized JavaScript origins, isi alamat halaman ini:
  5. Salin Client ID, tempel di atas, lalu simpan.

⚠️ Halaman dibuka dari file langsung. Google menolak alamat ini. Buka lewat server lokal (python -m http.server 8000 → http://localhost:8000) atau hosting.
